# Claude for Open Source: evidence notes

These notes summarize the public Claude for Open Source application page as checked for this project on 10 November 2026. Program criteria can change; confirm the live page and terms before applying.

Official page: <https://claude.com/contact-sales/claude-for-oss>

The page lists several alternative routes, including:

- **Maintainers and library authors:** 500+ dependent repositories, 100+ dependent packages, or 200,000+ combined monthly downloads across public registries.
- **Core contributors:** a listed committer or maintainer on a recognized foundation or language project.
- **Active contributors:** 100+ pull requests merged into repositories the applicant does not own in the last 12 months.
- **Community builders:** 20+ unique external contributors with merged pull requests in one of the applicant's repositories in the last 12 months.
- **Critical infrastructure:** a maintained repository with an OpenSSF Criticality Score of 0.4 or above.

The application page also invites maintainers of projects the ecosystem quietly depends on to apply and explain their impact even if they do not meet a listed threshold.

## What this project can help with

OSS Evidence Kit is intentionally scoped to candidate evidence for the active-contributor and community-builder routes. It does not establish the final status of a candidate. The program's use of words such as **external** and **don't own** requires human review beyond what public GitHub search data can determine.

The tool cannot make a new repository eligible by itself. It also cannot create genuine project dependencies, merged pull requests, maintainership roles, or critical-infrastructure status. Those require sustained, independently verifiable work and adoption.
